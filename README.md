# BuildCalc Studio

Школьный проект Алидара Сарымсакова 11N Планирование материалов и бюджета небольшого ремонта. Чистые HTML, CSS и JavaScript, без сборщика и серверной базы.

## Запуск

Откройте `dist/index.html`. В скачиваемом архиве исходников файлы лежат в корне, поэтому открывайте `index.html`. Интернет нужен только для необязательного шрифта, без него используется Arial. Для надёжного localStorage рекомендуется опубликованный сайт или локальный HTTP-сервер: правила сохранения файлов file:// зависят от браузера.

## Файлы

- index.html — страницы, формы, диалог подтверждения.
- styles.css — дизайн, адаптивная сетка, анимации, печать.
- calc.js — чистые функции расчётов и оптимизация покупки краски.
- app.js — состояние, обработчики, SVG-проекция, смета, сохранение и импорт.
- qa/workflows.cjs — проверка логики приложения с минимальной моделью DOM. Это не проверка визуального отображения в браузере.

## Возможности

- Краска, плитка, кирпич: проёмы, запас, целые упаковки, цена.
- Ползунки размеров, готовые примеры, переключение объёмной и плоской схемы, поворот, цвет стен.
- Открытые формулы и разделение количества по расчёту, покупки и остатка сверх расчёта.
- Подбор набора банок 1, 2,5, 5, 10 литров: минимальная стоимость и минимальный остаток.
- Добавление, редактирование и удаление позиций в общей смете.
- Бюджет с отображением оставшейся суммы или превышения.
- Именованные проекты и черновик в localStorage. Совместимость с сохранениями первой версии.
- Экспорт проекта в JSON, импорт на другом устройстве, CSV, печать/PDF.
- Импорт проверяет параметры и заново рассчитывает суммы, не доверяя цифрам из файла.

## Как работает подбор банок

Каждый доступный объём является кратным 0,5 л. Алгоритм переводит литры в целые половины литра и использует динамическое программирование: для каждого достижимого объёма хранит минимальную стоимость. Потом выбирает самый дешёвый достаточный набор и отдельно наименьший достаточный объём. Равные по цене варианты сравниваются по остатку. Цены сравниваются в целых сотых тенге. Максимальный объём подбора — 10 000 л.

Пример: расчёт 10,208 л; цены за 1 / 2,5 / 5 / 10 л — 3 200 / 6 800 / 12 500 / 23 500 ₸. Минимальная стоимость — 26 700 ₸ за 10+1 л. Три банки по 5 л стоят 37 500 ₸. Это сравнение введённых примерных цен, не гарантия экономии в магазине.

## Ограничения

Все цены примеров условные. Схемы не являются строительными чертежами, проёмы показаны условно. Запас выбирает пользователь. Остаток упаковок не равен измеренному количеству отходов. Параметры упаковок для подбора должны относиться к одному продукту с одинаковой укрывистостью.

Работа, доставка, клей, раствор и потолок в калькуляторе краски исключены. Кирпичная кладка оценивается приближённо: множитель 2 для стены в один кирпич. Расчёта несущей способности нет.

Данные находятся в этом браузере и могут исчезнуть после очистки хранилища. Для переноса и резервной копии используйте JSON. Сайт не синхронизирует данные автоматически.

## Проверки

В репозитории: `node --check dist/app.js`, `node --check dist/calc.js`, `node qa/workflows.cjs`. В архиве исходников для первых двух команд уберите `dist/`.

Формулы трёх материалов проверены на известных примерах. Оптимизатор сравнивался с полным перебором на 30 сочетаниях объёмов и цен. Проверка с моделью DOM покрывает добавление и редактирование, подбор упаковок, сохранение, импорт и отклонение ошибочных данных. Настоящий браузер и визуальная проверка в этой среде недоступны.
